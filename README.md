# e aí, marcou?

PWA para busca, comparação e agendamento de consultas.

## Arquitetura

Frontend
- React
- Vite
- TypeScript
- Tailwind CSS

Backend
- Python
- FastAPI
- Pydantic

Banco de dados
- Firebase
- Cloud Firestore

PWA
- Web App Manifest
- Service Worker
- Estratégias de cache/offline
